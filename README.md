# Python Statistical & Pandas Analysis

A Python practice repository focused on Pandas-based data analysis and introductory statistical programming with Statsmodels.

## Structure
- `Pandas/project/Pandas.ipynb` — main Pandas analysis notebook.
- `Pandas/project/Project Analysis Report` — supporting documentation.
- `Pandas/project/Readme.Md` — project documentation.
- `Pandas/work01.txt`–`work08.txt` — practice files.
- `Statsmodels/test01.py`–`test04.py` — Statsmodels exercises.

## Analysis Workflow
The Pandas project documents data loading, exploration, cleaning, filtering, descriptive statistics, grouping, aggregation, and interpretation.

## Technologies
Python, Pandas, NumPy, Statsmodels, and Jupyter/Colab notebook workflow.

## Getting Started
Open `Pandas/project/Pandas.ipynb` in Jupyter, JupyterLab, Google Colab, or a compatible notebook environment.

For a Statsmodels exercise: `python Statsmodels/test01.py`

## Skills
Data exploration, cleaning, DataFrame manipulation, filtering, descriptive statistics, grouping/aggregation, numerical analysis, and Python analytical workflows.
